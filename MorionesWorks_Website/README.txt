# MorionesWorks Website Prototype

## Run it
1. Extract the ZIP file.
2. Open the `MorionesWorks_Website` folder.
3. Double-click `index.html` or open it using VS Code Live Server.

## Included
- Responsive customer-facing storefront
- Product search and category filtering
- Shopping bag with quantity controls
- Demo checkout and order creation
- Admin demonstration panel for products, inventory, orders, and project modules
- Uploaded MorionesWorks logo in `assets/`

## Important project notes
This is a **frontend prototype** for the Chapter 1 project. It uses sample product listings and browser `localStorage`. It does not yet include a real database, secure administrator login, customer account registration, online payment gateway, live delivery integration, or production receipt/report generation. The admin panel is a demonstration only and must not be used with real customer data.

The sample product photos are loaded from Unsplash URLs and therefore require an internet connection. Replace sample names, prices, stock counts, descriptions, and photos with verified information from participating artisans and suppliers.

## Suggested next development stage
Connect the interface to a backend (for example PHP + MySQL) with secure authentication, role-based access, validated order processing, inventory transactions, delivery records, expense records, and generated receipts/reports. Follow the exact scope and limitations in the approved project document.
